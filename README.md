## 🚀 Как запустить бота

### Шаг 1 — Установи Python
Скачай Python 3.10+ с сайта python.org (если ещё не установлен)

### Шаг 2 — Установи зависимости
Открой папку с ботом в терминале и выполни:
```
pip install -r requirements.txt
```

### Шаг 3 — Вставь токен
Открой файл `bot.py` и найди строку:
```python
BOT_TOKEN = "ВСТАВЬ_СЮДА_НОВЫЙ_ТОКЕН"
```
Замени на свой новый токен от @BotFather.

### Шаг 4 — Запусти бота
```
python bot.py
```

## 📱 Как запустить на сервере (чтобы бот работал 24/7)

### Вариант 1 — Railway.app (бесплатно, просто)
1. Зарегистрируйся на railway.app
2. Создай новый проект → Deploy from GitHub
3. Загрузи файлы бота
4. В Environment Variables добавь: `BOT_TOKEN=твой_токен`
5. В `bot.py` замени строку токена на: `BOT_TOKEN = os.getenv("BOT_TOKEN")`

### Вариант 2 — VPS (любой хостинг)
1. Загрузи файлы на сервер
2. Установи зависимости: `pip install -r requirements.txt`
3. Запусти через screen или systemd
