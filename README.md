# 汉助 HanZhu v4

Бот-помощник по китайскому от Лазизы · @qing_laoshi

## Запуск

1. Распакуй архив в `Загрузки`. Нужна папка, где **сразу** лежит `bot.py`.
2. В командной строке (Win + R → `cmd`):
   ```
   cd Downloads\hanzhu4
   notepad .env
   ```
   Замени `ВСТАВЬ_СЮДА_ТОКЕН_ОТ_BOTFATHER` на токен, сохрани (Ctrl+S).
3. `pip install -r requirements.txt` (десять секунд, компилятор не нужен)
4. `python bot.py`

Должно появиться `🐉 汉助 HanZhu запущен`. Пока окно открыто, бот работает.

**Уже запускала прошлую версию (hanzhu3)?** Скопируй из её папки файл `hanzhu.db`
в папку `hanzhu4`. Ученики, уроки и оплаты подхватятся, база обновится сама.

## Что умеет

**Любой пользователь:** знакомство, приветствие с рассказом, что умеет бот (`/about`) (язык, имя, откуда узнал, уровень), слово дня,
чэнъюй, факт о Китае, мини-словарь, смена языка кнопкой «🌐» или `/lang`.
Четыре языка: русский, узбекский, английский, китайский. Язык выбирается первым шагом.

**Ученик:** «📊 Мой прогресс» (уроки, оплата, остаток, тесты полосками, динамика, расписание),
напоминания об уроках с кнопками «Буду / Не смогу».

**Ты, через `/admin`:**
- сделать человека учеником
- записать урок (с темой), оплату, результат теста, отменить ошибочный урок
- задать расписание: `пн 18:00, ср 18:00` (время по Ташкенту)
- задать ссылку на Zoom
- напомнить ученику об оплате мягким сообщением одной кнопкой

Слово показывается из того источника, что стоит выше в таблице: твои списки главнее автоматических,
одно слово не повторяется. Всего слов 11 361, из них 3 311 с русским переводом.
Файлы `content_hsk.txt` и `content_chengyu_cedict.txt` собраны автоматически, руками их не правь.

**Как добавить:** на GitHub открой нужный файл → значок карандаша → допиши строку → **Commit changes**.
Railway сам перезапустит бота. Строка с ошибкой пропускается, остальное работает.

**Уровни.** Твои списки уровней 1–4 это HSK 3.0, уровень 5 и таблица `content_hsk5.txt` это HSK 2.0.
В ответе бота у таких слов стоит пометка (3.0) или (2.0). У автоматического списка уровни 1–6 по HSK 2.0,
уровень 7 значит «вне HSK 2.0». У чэнъюй уровень равен самому сложному иероглифу.

**БКРС.** Бот не копирует БКРС, а даёт ссылку: `https://bkrs.info/slovo.php?ch=слово`. Адрес я проверить
не могла. Если ссылка не открывается, поменяй одну строку `BKRS_URL` в `bot.py`.

## Перевод слов на русский и узбекский

Слова автоматического списка идут с английскими значениями. Чтобы перевести остальные (около 7 400, из них 1 844 на уровне HSK 6), есть скрипт `translate_words.py`. Он отправляет слова порциями в Claude API и записывает результат в `content_translations_auto.txt`; бот подхватывает его сам.

1. Получи ключ API на сайте Anthropic (это отдельная платная подписка, не та, что у чата).
2. В командной строке, в папке с ботом: `set ANTHROPIC_API_KEY=твой_ключ` (ключ никуда не записывается, не отправляй его в чат и не загружай на GitHub).
3. `python translate_words.py --dry-run` покажет, сколько слов и токенов. `--limit 200` переведёт пробные 200, `--level 6` только слова HSK 6.
4. `python translate_words.py` переведёт всё. Можно остановить в любой момент и запустить снова: сделанное он пропустит.
5. Загрузи получившийся файл на GitHub.

Переводы не проверены носителем. Узбекские стоит просмотреть выборочно и править прямо в файле.

## Грамматика

Кнопка «📐 Грамматика» показывает модель по уровню, который человек выбрал в начале. Листается
стрелками, уровень можно переключить. Каждое нажатие даёт следующую ещё не виденную модель.
Для HSK 7 и выше грамматики пока нет, бот честно говорит об этом и показывает HSK 6.
Объяснения только по-русски. Свои модели добавляй в `content_grammar.txt` (формат в шапке файла).

## Тексты для чтения

Кнопка «📖 Тексты»: адаптированные тексты по уровню человека и классика (стихи, общественное достояние).
Китайский, пиньинь и перевод под спойлером. Сейчас по 15 текстов на каждый уровень от HSK 1 до HSK 6 и 6 стихотворений.
**Пиньинь собран автоматически и сверен со словарём (см. `pinyin_report.md`), но носителю его всё равно стоит просмотреть.** Формат блока и правила в шапке `content_texts.txt`.

**Картинки к текстам.** Положи файл в папку `images` (на GitHub: Add file → Create new file → имя
`images/README.txt`, потом загружай картинки туда) и впиши в блок текста строку `@image images/h1-01.jpg`.
Бот отправит картинку, а текст будет подписью к ней.

## Раздел 16+

Кнопка «🔞 Ругательства 16+»: 36 слов со степенью грубости. Откровенной сексуальной лексики там нет.
Человек должен нажать «Мне есть 16». **Это только нажатие кнопки, возраст не проверяется.** Поэтому в
карточке ученика есть кнопка «🔞 Закрыть / открыть 16+»: детям раздел закрывай сам. Закрытый раздел
человек открыть не может. Отметка хранится в базе, `/mydata` и `/deletemydata` её учитывают.

## Знакомство и профиль бота

Новый человек видит выбор языка (каждый на своей строке, рядом флаг), и сразу после
выбора приходит приветствие от 茶茶 на его языке. Имя везде одно, 茶茶, а в скобках написание
на языке человека: ЧаЧа, ChaCha, Chá Chá. Потом бот спрашивает имя, откуда узнал, уровень
и в конце рассказывает, что умеет.

**Описание, «о боте» и имя бота в Telegram бот выставляет сам при запуске**, на четырёх языках.
Тексты лежат в `texts.py` в разделе `PROFILE`. Если поменяешь их и перезапустишь, обновится само.
Руками в @BotFather нужно только фото: `/mybots` → бот → **Edit Bot** → **Edit Botpic**.

**Конфиденциальность.** Команда `/privacy` показывает, какие данные бот хранит.
Команда `/mydata` присылает человеку файл со всем, что бот о нём хранит. Команда `/deletemydata`
с подтверждением стирает всё. Исправить данные, ограничить обработку или отозвать согласие
человек может, написав тебе через бота, это делаешь ты вручную.
Текст политики для публикации на отдельной странице лежит в `privacy_policy.md`.

## Стикеры

Бот отправляет стикеры в живых моментах, а не на каждый чих:

| Стикер | Когда |
|---|---|
| 👋 hello | после знакомства, перед приветствием |
| 🙏 thanks | ученику, когда записана оплата |
| 🎉 celebrate | когда результат теста вырос по сравнению с прошлым |
| 🤔 thinking | когда слова нет в словаре |
| 📖 study | вместе с напоминанием за час до урока |
| 😴 sleepy | про запас, пока нигде не используется |

**Как задать:** создай набор в Telegram, затем просто пришли боту любой стикер из него.
Бот спросит, для чего он, нажми нужную кнопку. `/stickers` покажет, что уже задано.
Если стикер не задан, бот просто пропускает его. Ничего не ломается.

## Как работают напоминания

- **За сутки** ученику приходит «Занятие завтра в 18:00. Всё в силе?» с двумя кнопками.
  - «Буду» → тебе приходит строка о подтверждении.
  - «Не смогу» → бот просит причину и передаёт её тебе. Если до урока меньше 3 часов,
    он отметит это и напомнит ученику правило про оплату.
- **За час** приходит короткое напоминание со ссылкой на Zoom.
- Каждое напоминание уходит один раз, повторов нет.
- **Только пока бот запущен.** Если окно закрыто или компьютер спит в момент
  напоминания, оно пропадёт. Для круглосуточной работы нужен хостинг.

## Связь с тобой

Если ученик или подписчик пишет боту что-то своё, бот передаёт это тебе.
Чтобы ответить, нажми «Ответить» (reply) на пересланное сообщение, и текст уйдёт человеку
от твоего имени. Бот сообщает человеку, что ответит сама Лазиза.

## Отчёт по воскресеньям

В воскресенье после 20:00 по Ташкенту приходит итог недели: сколько уроков проведено,
сколько новых людей, сколько отмен, чем пользуются чаще всего, кому пора напомнить об оплате.

## Круглосуточная работа на хостинге (Railway)

Настройка занимает минут пятнадцать. Названия кнопок на сайте могут чуть отличаться.

1. **GitHub.** Открой репозиторий `hanzhu-bot` → **Add file → Upload files** и перетащи туда
   все файлы из этой папки, **кроме `.env`** (в нём токен, на GitHub ему не место).
   Старые файлы с такими же именами заменятся. Старый `database.py` можно удалить.
2. **Railway.** Зайди на railway.com через GitHub → **New Project → Deploy from GitHub repo**
   → `hanzhu-bot`.
3. **Переменные** (вкладка Variables), три штуки:
   - `BOT_TOKEN` = токен от @BotFather
   - `OWNER_ID` = `8594239159`
   - `DATA_DIR` = `/data`
4. **Том для базы.** Добавь **Volume** к сервису и укажи путь монтирования `/data`.
   Без этого база стирается при каждом обновлении, и все ученики пропадут.
5. **Команда запуска** (Settings → Start Command): `python bot.py`.
   Публичный адрес сервису не нужен.
6. Открой логи деплоя. Когда увидишь `🐉 汉助 HanZhu запущен`, всё работает.
7. **Закрой бота на ноутбуке.** Две копии одного бота одновременно не работают,
   Telegram выдаёт ошибку конфликта.

### Резервные копии

Раз в неделю вместе с итогами приходит файл базы. В любой момент можно получить копию
командой `/backup`. Сохраняй их у себя: это единственная страховка, если хостинг сломается.

## Если что-то не так

- **`No module named 'telebot'`** → не в той папке или не прошёл шаг 3.
- **`Не найден токен бота`** → не сохранился `.env`, проверь отсутствие пробелов и кавычек.
- **Бот молчит** → закрыто окно с `python bot.py`, либо в нём красный текст.
- **Бот отвечает дважды** → запущена вторая копия, закрой лишние окна.
